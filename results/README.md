2. `historical-control-incident.json` — the terminal 835,446-obligation breach.
3. `campaign-ledger.json` — raw later two-run ledger, retained with a warning; not a valid fresh campaign.
4. `resource-usage.json` — measurements of those later post-breach runs.
5. `HISTORICAL-SOURCE-LIMITATION.md` — missing pre-V3 two-column session-codec dependency for the 12 archived labels.
6. `semantic.json`, `case-outcomes.csv`, and `summary.csv` — archived checker outputs.

Session mutations compare canonical bytes and are not signature-forgery experiments. The current unit tests and archived outputs do not prove the article's general theorems.
